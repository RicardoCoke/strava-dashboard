# Features

One folder per feature: `NNN-short-slug/` containing

- `intent.md` — why and what outcome (written by `intent-extractor`, approved by you)
- `specs.md` — how it will be built and tested (written by `spec-writer`, approved by you)
- `review.md` — independent review of the implementation (written by `reviewer`)

Start a feature in Claude Code with something like:

> New feature: I want a chart of my weekly running distance for the last few months.
